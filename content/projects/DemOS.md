## Overview

This project is a desktop application that visualizes core Operating System concepts including CPU scheduling, memory management, disk scheduling, and process management. Built with Python and Tkinter for educational and demonstrative purposes.

## Features

- **CPU Scheduling**: Algorithms including FCFS, SJF, Priority, and Round Robin
- **Memory Management**: First Fit, Best Fit, and Worst Fit allocation strategies
- **Disk Scheduling**: FCFS, SSTF, SCAN, C-SCAN, LOOK, and C-LOOK algorithms
- **Process Manager**: Interactive process creation and termination with live memory allocation visualization

## Tech Stack

- **Language**: Python 3.8+
- **GUI Framework**: Tkinter

## How to Use

### Requirements
- Python 3.8 or later
- Tkinter (included with most Python distributions)

### Installation
If Tkinter is not available:
```bash
pip install tkinter
```

### Running the Application
```bash
python main.py
```
